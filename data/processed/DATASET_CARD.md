# Processed Data Card

Processed datasets are generated artifacts and are not committed.

Expected generated files include:

- `sft_train.jsonl`, `sft_valid.jsonl`
- `orpo_train.jsonl`, `orpo_valid.jsonl`
- `grpo_prompts.jsonl`, `grpo_persona_prompts.jsonl`
- `mari_bench_v1.jsonl`
- `base/`, `base_long/`, and persona split directories for larger runs

Rows should be derived only from approved source licenses unless a separate
license audit explicitly allows broader use.
