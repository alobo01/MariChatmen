# Processed Data

This directory is intentionally kept mostly empty in the repository.

Generated files such as `sft_train.jsonl`, `orpo_train.jsonl`,
`grpo_prompts.jsonl`, `base/`, `base_long/`, and persona split directories are
recreated by the build scripts and ignored by git.

For smoke checks, the scripts can fall back to
`tests/fixtures/spanish_sft_fixture.jsonl`.
